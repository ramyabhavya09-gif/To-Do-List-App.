
# To-Do List App

## Description
A simple and user-friendly To-Do List web application built using HTML, CSS, and JavaScript. It helps users organize daily tasks by adding, completing, and deleting tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Delete individual tasks
- Clear all tasks
- Save tasks using browser local storage
- Responsive and clean user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Project Structure
```text
To-Do-List-App/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Enter a task and click Add.
4. Check the box to complete a task or click Delete to remove it.

## Purpose
This project demonstrates basic web development,
DOM manipulation, event handling, and local storage.
